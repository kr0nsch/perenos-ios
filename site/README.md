# Сайт «Переноса»

Статическая страница проекта для GitHub Pages: HTML, CSS и небольшой JavaScript.
Для локального предпросмотра используются npm и Vite; на готовой странице нет
внешних шрифтов, скриптов, аналитики или обязательных сетевых запросов.

## Локальный предпросмотр

Нужны Python 3.11+ и Node.js с npm. Из корня репозитория:

```powershell
npm ci
npm run dev
```

Откройте адрес, который покажет Vite (по умолчанию `http://localhost:5173/`).
Параметры сервера передаются после `--`, например:

```powershell
npm run dev -- --host 127.0.0.1 --port 7100
```

`npm run dev` сначала собирает страницу в `artifacts/site`, затем запускает Vite.
Скрипт сборки использует только стандартную библиотеку Python. Он копирует нужные
скриншоты, два русских GIF в двух темах, иконку и локальные Manrope / IBM Plex Mono
с OFL-лицензиями, проверяет локальные ссылки и создаёт `robots.txt`, `sitemap.xml`
и `.nojekyll`.

Для проверки под базовым путём GitHub Pages:

```powershell
python site/build.py --output artifacts/preview/perenos-ios
npx vite artifacts/preview --host 127.0.0.1 --port 7100
```

Откройте `http://127.0.0.1:7100/perenos-ios/`. Не запускайте повторную сборку в
каталог, который уже обслуживает Vite: сборка полностью заменяет выходную папку.
Очищается только выбранная папка строго внутри `artifacts`; сам `artifacts`, пути
вне него и ссылки наружу отклоняются до изменений.

## Интерфейс и медиа

Кадр восстановления снят с актуального интерфейса Perenos в деморежиме;
устройства, аккаунт и приложения смоделированы. Кадры сценариев переноса
и GIF записаны в интерфейсе 1.3.0 и подписаны соответственно. GIF запускаются по
кнопке и не загружаются до неё. Смена сценария или темы останавливает анимацию. Вкладки работают с клавиатуры,
выбранная тема хранится только в `localStorage` браузера. Без JavaScript остаются
статичные изображения и оба текстовых сценария, а кнопки темы и воспроизведения скрыты.

Кнопки загрузки по умолчанию открывают последний релиз на GitHub. Если публичный
API GitHub доступен, они ведут прямо на установщик и портативный ZIP последнего
стабильного релиза. Устанавливаются только URL файлов из
`github.com/kr0nsch/perenos-ios/releases/download/`; при ошибке или лимите API
исходные ссылки продолжают работать.

Браузерные проверки используют установленный Microsoft Edge и сами останавливают
запущенный ими сервер:

```powershell
npm run test:site
```

## Превью ссылки

`social-card.svg` — редактируемый векторный исходник обложки 1200 × 630 для Open Graph,
без внешних ресурсов. `social-card.png` — готовая обложка тех же размеров. После
изменения SVG заново отрендерите PNG в браузере с масштабом 1 и проверьте, что текст
и графика не обрезаны.

Сборка копирует PNG в `assets/social.png`, а исходный SVG — в
`assets/social-card.svg`. Публикацией управляет `.github/workflows/pages.yml`.
Отдельный сервис хостинга не используется.
