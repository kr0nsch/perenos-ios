# Сайт «Переноса»

Статическая страница проекта для GitHub Pages: HTML, CSS и небольшой JavaScript.
Зависимости npm, внешние шрифты и аналитика не используются.

Из корня репозитория:

```powershell
python site/build.py
python -m http.server 8766 --bind 127.0.0.1 --directory artifacts/site
```

Откройте `http://127.0.0.1:8766/`. Скрипт сборки копирует только нужные
скриншоты и GIF из `docs`, проверяет локальные ссылки и создаёт `robots.txt`,
`sitemap.xml` и `.nojekyll`. Для проверки под путём GitHub Pages можно собрать
в `artifacts/preview/perenos-ios`, запустить сервер из `artifacts/preview`
и открыть `/perenos-ios/`.

Перед сборкой очищается только выбранная выходная папка строго внутри
`artifacts`. Сам `artifacts`, пути вне него и ссылки наружу отклоняются до
изменений. Старые и посторонние файлы из предыдущей сборки не публикуются.

Картинки `apps-*` и `saved-*` — снимки настоящего интерфейса в деморежиме;
устройства и приложения в них смоделированы. GIF загружаются только после
нажатия «Воспроизвести демо». Переключение сценария останавливает анимацию.
На странице есть светлая и тёмная темы; выбор хранится только в браузере.

Кнопки загрузки по умолчанию открывают последний релиз на GitHub. Если
публичный API GitHub доступен, они ведут прямо на установщик и портативный ZIP
последнего стабильного релиза. Устанавливаются только URL файлов из
`github.com/kr0nsch/perenos-ios/releases/download/`; при ошибке или лимите API
исходные ссылки продолжают работать.

## Превью ссылки

`social-card.svg` — редактируемый исходник обложки 1200 × 630 для Open Graph.
В нём используется встроенная копия существующей иконки приложения; внешних
ресурсов нет. После изменения текста или композиции отрендерите SVG в браузере
при размере 1200 × 630 и сохраните PNG с теми же размерами как
`site/social-card.png`. Проверяйте, что текст и графика не обрезаны.

Сборка копирует PNG в `assets/social.png`, а исходный SVG — в
`assets/social-card.svg`. Пока PNG ещё не создан, для локального предпросмотра
используется скриншот приложения. Перед публикацией обновите PNG вместе с SVG.

Публикацией управляет `.github/workflows/pages.yml`. Исходники сайта находятся
в этом репозитории; отдельный сервис хостинга не используется.
