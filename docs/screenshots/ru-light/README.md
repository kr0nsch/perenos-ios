Реальный интерфейс «Переноса» **1.2.0** в деморежиме. Телефоны, приложения и аккаунт вымышлены. Кадры показывают последовательность действий и не измеряют скорость переноса.

Нажмите миниатюру, чтобы открыть полный кадр. Секции можно свернуть; анимации доступны отдельно: [Перенести сейчас](../../media/demo-ru-light.gif) · [Установить позже](../../media/later-ru-light.gif).
